# MIMIC LAB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page interactive 3D educational site about *Thaumoctopus mimicus* with an anatomy explorer, a mechanism lab and ten evidence-graded mimicry simulations.

**Architecture:** A React shell writes a Zustand store; an imperative Three.js `Engine` (lazy chunk) subscribes to it and owns one render loop. The octopus is procedural: every posture is a `PoseDefinition` (numbers only), so mimicry, locomotion and manual arm control are all the same blend of poses through a staged `TransitionSequence`. Educational content and mimicry definitions are plain data under `src/data/`.

**Tech Stack:** React 19, TypeScript 7, Vite 8, Three.js 0.187, Zustand 5, CSS Modules, Vitest 5, Playwright 1.65.

**Spec:** `docs/specs/product-spec.md`, `docs/specs/functional-spec.md`, `docs/specs/visual-spec.md`. Research: `docs/research/`.

## Global Constraints

- One route. No backend, no API keys, no downloaded 3D assets, no CDN requests.
- Exactly ten mimicry targets, each with `evidenceLevel` A/B/C, `references`, `limitations`, `reconstruction`.
- Exactly eight arms in every pose; arms may go under the sand but are never removed or scaled to zero.
- Pure animation maths (`src/three/animation/*`) must not import `three` renderer classes, React or the store, so it stays unit-testable in Node.
- Content strings live in `src/data/`, never inline in components or engine code.
- Copy never says the octopus "transforms into" or "becomes" another animal.
- No post-processing passes. Pixel ratio capped per quality tier (2 / 1.5 / 1).
- Colours and fonts only from `src/styles/tokens.css`.

## Review Focus

1. Switching mimicry target mid-transition: must blend from the current blended pose, with no snap. (Task 3 test.)
2. Scrubbing or replaying while paused: progress and phase must stay consistent. (Task 3 test.)
3. Arm pointing straight up or down (anemone, burrow): frames must not flip or produce NaN. (Task 2 test.)
4. Resize / orientation change with a view inset: animal stays centred in the free area. (Task 12 e2e, mobile project.)
5. WebGL context unavailable: fallback renders the content instead of a blank page. (Task 12 e2e.)

## Key Interfaces (shared by all tasks)

```ts
// src/three/animation/types.ts
export const ARM_COUNT = 8;                       // index 0..7 = L1,R1,L2,R2,L3,R3,L4,R4
export interface ArmPose {
  yaw: number;        // heading of the arm in the animal frame (rad). 0 = forward (+Z), + = animal's left (+X)
  pitch0: number;     // pitch where the arm leaves the body (rad, + up)
  pitch1: number;     // pitch at the tip
  pitchBias: number;  // exponent shaping where the pitch change happens (1 = even)
  bend: number;       // total lateral turn along the arm (rad)
  curl: number;       // extra curl concentrated near the tip (rad, + = aboral/up)
  length: number;     // extension factor, 0.35..1.25 (volume preserved: radius scales by 1/sqrt)
  bury: number;       // 0 = stays on/above sand, 1 = allowed fully below the sand surface
  waveAmp: number;    // travelling-wave amplitude (rad)
  waveFreq: number;   // waves along the arm
  waveSpeed: number;  // cycles per second
  wavePhase: number;  // phase offset (rad)
  waveAxis: number;   // 0 = lateral wave, 1 = vertical wave
}
export interface BodyPose {
  height: number;        // head centre above the sand (model units); negative = sunk in burrow
  mantlePitch: number;   // 0 = mantle trails horizontally behind the head, + = raised
  mantleLength: number;  // scale factors, 1 = rest
  mantleWidth: number;
  mantleHeight: number;
  headPitch: number;
  eyeRaise: number;      // 0..1 eye stalk extension
  webSpread: number;     // 0..1 web depth shown between arm bases
  burrow: number;        // 0..1 burrow mouth + mound visibility
}
export interface SkinPattern {
  dark: [number, number, number];   // linear RGB
  light: [number, number, number];
  bandFreq: number; bandContrast: number; bandSharpness: number;
  mottle: number; pale: number; texture: number;   // texture = papillae bump amount 0..1
}
export interface MovementParams {
  bobAmp: number; bobFreq: number;
  swayAmp: number; swayFreq: number;     // body yaw oscillation
  rollAmp: number;                        // body roll oscillation
  pulseAmp: number; pulseFreq: number;    // mantle / bell pulsing
  travel: number;                         // seabed treadmill speed (units/s), + = animal moves forward
  hover: number;                          // extra height oscillation baseline
}
export interface PoseDefinition { body: BodyPose; arms: ArmPose[]; skin: SkinPattern; movement: MovementParams; }
export type Channel = 'prep' | 'arms' | 'body' | 'skin' | 'movement';
export interface TransitionPhase { id: PhaseId; label: string; start: number; end: number; channel?: Channel; }
export interface TransitionSequence { duration: number; phases: TransitionPhase[]; }
```
